# Inbox

Drop files here for the `/log` skill to process into memory.

- Any format: `.txt`, `.md`, `.docx`, `.pdf`, `.csv`, screenshots.
- Suggested naming: `YYYY-MM-DD-short-description` (not required).
- After you drop files, run `/log` in a Claude Code session in this project to process them.
- Processed files are moved to `archive/` — nothing is ever deleted.
