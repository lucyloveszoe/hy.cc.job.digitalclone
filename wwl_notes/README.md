# WWL Notes

Drop rough notes here for the `/draft-wwl` skill to turn into a draft "In Progress"
carry-forward list for your weekly WWL status report.

- Any format: bullet points, pasted emails, chat logs, plain text/markdown.
- Write about whatever happened this week on whichever threads you want reflected —
  no required structure, the skill will match your notes against known open threads.
- After you drop notes, run `/draft-wwl` in a Claude Code session in this project.
- Processed notes are moved to `archive/` — nothing is ever deleted.
- This only drafts the "In Progress" project/support list. Complete / New / Production
  Support / IT Support sections are still yours to write.
