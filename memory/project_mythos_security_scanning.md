GTO-mandated code security scanning program ("Mythos"), using Claude models (initially claude-sonnet-4-6, later "Mythos-5") via a GTO tool called "brcm-scan." Runs across two tracks:

**SW-team-owned repos**: 80 active repos scanned, completed 06/30/2026 — 209 "Mythos New" findings out of 815 total findings, across roughly 8 vulnerability categories (Excel formula injection, zip path traversal/zip bombs, SQL/NoSQL injection, IDOR, XSS/SSRF, credential exposure). Cost ~$28,580 (2.53B input / 65M output tokens), funded by Broadcom centrally. Remediation (Ken/Yu Han/Chao) targets completion 10/13/2026. Going forward, all new WSD releases/upgrades go through a Mythos scan by default (skip-list reserved for explicitly flagged legacy projects) — see [[feedback-engineering-principles]] for the formal Round1→Round2→Round3 scan/fix cycle this program established.

**Non-SW-team-owned repos**: a much larger, messier population — found to be "out of control" (no naming convention, no owner/team metadata, inconsistent default branches). This scan grew from ~271-300 repos triaged (delete/scan/keep/pending-owner-ack) to 136 non-SW GitHub repos with 1,800 findings (213 false-positive, 1,587 outstanding) by ww32. Also covers 34 FtC GitLab packages (scan completed ww29). Funded by the BU rather than centrally once the scan moved past SW-owned repos and switched to the "Mythos-5" model (from 07/05/2026). This scan's findings directly triggered [[project-git-repo-standardization]].

Yu Han personally led the SW-owned-repo scan to completion and temporarily covered a teammate's ownership of the non-SW-team scan for about 9 days.

**Cost risk**: the Mythos-scanning budget cap ($30K) was fully consumed by 07/28/2026 with an unexplained cost spike under investigation with GTO.

**Why:** a GTO-wide compliance mandate with real budget and remediation-deadline pressure, not optional hardening — and the root cause of the separate repo-governance cleanup effort. Note this is the team's second security-hardening wave: an earlier, distinct 2023 effort (AssumeRole + Cycode-flagged secrets cleanup, unrelated tooling) is recorded in [[project-2023-annual-review]].

**Intermediate chapter — Cycode vulnerability/security scan rollout across 150+ repos (Feb 2025)**: distinct from both the 2023 Cycode secrets-cleanup and the 2026 Mythos/brcm-scan program above — this is a Broadcom-Enterprise-GitHub-level (Ravi) integration of Cycode's vulnerability + security scanning (not just secrets) across all of WSD's 150+ GitHub repos, as part of general production-resiliency/cybersecurity improvement. Kicked off 02/04/2025; Cycode integrated into the BRCM tool suite and demoed to SW team 02/12/2025 (PR-blocking to force-fix vulnerabilities not yet enabled); Chao/Jiapeng/Ken attended a Cycode deep-dive webinar 02/27/2025 covering false-positive mitigation for secret scanning, a workflow-notification UI mock, and vulnerability/compliance reporting — follow-up with Ravi on WSD's specific integration progress still in progress as of 03/04/2025.
