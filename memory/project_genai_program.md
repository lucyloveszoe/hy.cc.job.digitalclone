Durable GenAI governance policy at WSD/Broadcom GTO, consistent across all weekly reports ww01–ww10 (2026) — relevant to Yu Han's Broadcom WSD AI Champion role:

- All AI tool use requires GTO/OneTrust approval; local MCP servers are prohibited; cloud LLM use is restricted to non-critical IP; production AI use cases require BU-GM-approved ROI (with a documented hypothesis, time-limited as a POC first).
- **Cursor** is the production-approved coding assistant (OneTrust #29279): $32/user/month, FY26 quota fixed at 120 seats, fully assigned and rotated monthly by Yu Han's team.
- **GCA/GitHub Copilot** enterprise licenses were frozen and are being sunset (users off by 10/31/2025) in favor of Cursor/Gemini-Canvas.
- **Gemini/Canvas** approved (OneTrust #33141) as a low/medium-IP-risk coding alternative to Cursor.
- **Vectara** was chosen over PAIS for WSD's private AI agents — WSD recommended it 12/12/2025 after a POC, GTO announced the adoption decision 01/18/2026. Internal GenAI agents must run on-prem via Vectara; GCP-hosted GenAI is reserved for external-customer-facing use only.

WSD's own GenAI agents (built on Vectara) are tracked against an accuracy bar: as of ww09/ww10 (Mar 2026), the Clotho and MARA agents passed the >85% accuracy target; the PRA agent was still improving at ~70%. Production OneTrust cases: Clotho #38755, MARA #38801, PRA #40288 — all had GCM-approved ROI statements and were in GTO review as of ww11 (03/17/2026). GTO's PAIS POC chatbot environment was permanently shut down 03/27/2026, making Vectara WSD's sole production chatbot/agent platform going forward.

**Quality regression (ongoing risk, ww15 onward)**: after a Vectara production infrastructure upgrade (~05/04/2026), all three agents regressed vs. their POC baselines — Clotho slightly below POC, MARA and PRA "much worse." Vectara identified a Broadcom-Tanzu integration bug corrupting tokens (found 05/25/2026) requiring another fix. Yu Han escalated to GTO for a dedicated staging environment. This pushed the G-AI Portal Phase II target out 3 weeks to 07/14/2026. Unresolved as of ww22 (06/02/2026) — update this section as the fix lands.

**AI coding tool cost-routing policy** (see [[feedback-engineering-principles]] for the full principle): default to Gemini over Claude for day-to-day coding, "Plan with Claude, Build with Gemini" for complex work, <$200/month per-user cap — set 03/31/2026, new Cursor pricing model effective 04/01/2026 with a planned move to API-pooled usage from Nov 2026. A proposed (not yet finalized, as of ww22) refinement: a low default per-user token cap (~50) plus a reserved 10-20K sub-pool for ~40 identified high-usage "power users," with manager approval for extra credits.
